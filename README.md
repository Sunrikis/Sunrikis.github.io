# Sunrikis · 无意识庭院

GitHub Pages 静态主页「无意识庭院」，以古明地恋多画风同人插画与植物系静物为视觉线索，展示研究、日常兴趣（游戏、音乐、动漫）与学习札记。支持深浅主题、专注阅读，以及可键盘操作的多天气与双场景图像退化对比。

只使用昵称。不公开实名、学校、联系方式、成绩、履历、作者名单或实验数据。论文仅展示题目、会议、年份和确认的录用状态，不将准备投稿写成发表。

正文 19px，辅助字号至少 16px。内容区占 94% 屏宽，上限 1800px。

修改 `js/profile.js` 后运行 `node scripts/build-cv.cjs`，同步首页的资料区和可打印概览。首页正文可直接阅读，启用 JavaScript 后可使用主题、阅读和对比控件。使用本地静态服务器预览。

## 插画

- `assets/koishi-garden-v2.png` 使用内置 imagegen 生成，古明地恋同人作品，不是站主肖像。提示词见 `assets/koishi-prompt.txt`。
- 多画风立绘与微缩静物（厚涂花房、Q 版探头、水彩茶会、像素漫步、藏书票印章及 4 件静物小物件）经 WebP 优化后存于 `assets/`，美术企划与提示词见 `assets/koishi-art-brief.md`。

## 发布约定

每次完成修改与检查后，强制推送到本仓库 origin/main；始终以无父提交的快照替换远端，main 历史只保留一个提交。提交作者使用 Sunrikis 与 GitHub noreply 地址。不要推送私有材料、编辑器文件或 QA 产物。
